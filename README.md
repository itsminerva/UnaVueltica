# UnaVueltica
Visita la pagina aqui https://unavueltica.netlify.app/
Landing page editorial en HTML standalone para **UnaVueltica** — agencia de asesoría de visados y viajes a Europa.

## ✨ Características

- **Diseño editorial premium** con paleta azul profundo + dorado
- **Tipografía refinada**: Cormorant Garamond (display) + DM Sans (body)
- **100% standalone**: un solo archivo `.html` con imágenes embebidas en base64
- **Sin dependencias externas**: no requiere build, npm ni servidor
- **Animaciones suaves** y transiciones cuidadas
- **Responsive**: adaptado a móvil, tablet y desktop

## 📑 Secciones

- **Hero** con llamada a la acción y brújula animada
- **Misión, Visión y Valores**
- **Requisitos de visa** en acordeón ilustrado
- **Talleres** y formaciones
- **Experiencias** en carrusel infinito
- **Testimonios** de viajeros
- **CTA final** y footer

## 🚀 Uso

Abre el archivo `unavueltica.html` directamente en cualquier navegador moderno. No requiere instalación.

```bash
open unavueltica.html
```
